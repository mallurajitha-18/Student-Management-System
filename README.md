# Student Management System (MVC Application)

## Description
This is a **Student Management System** built using the **MVC (Model-View-Controller) Architecture**. It includes features such as user registration, login, update, and delete operations, all connected to a MySQL database using JDBC for database connectivity and data manipulation. 

The system also integrates a frontend with **HTML**, **CSS**, and **JavaScript** for an interactive user interface. Secure login functionality is implemented with **session management** to ensure safe access to the system.

## Features
- User registration and login functionality
- View, update, and delete student records
- Secure login with session management
- Interactive UI with frontend technologies: **HTML**, **CSS**, **JavaScript**
- Backend handling with **Java**, **Servlets**, and **JDBC**
- Database management with **MySQL**

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Java, Servlets
- **Database**: MySQL
- **Database Connectivity**: JDBC (Java Database Connectivity)

## Setup Instructions

### Prerequisites
- **Java 8+** installed on your system
- **Eclipse IDE** (or any other Java IDE)
- **MySQL** installed and running on your machine
- **Apache Tomcat** or any other servlet container for running the app
- **Git** installed to clone the repository
